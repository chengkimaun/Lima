Literature Matrix: Word Add-in Guide

Everything you need to write, cite, and format directly within Microsoft Word.

1

Getting Started

  • Open Literature Matrix: Launches main application.
  • Help: Opens this user guide.
2

Library Setting Group

  • Current Library: Dropdown to switch active database files.
  • Open/Switch Library: Manually browse & select files.
  • Refresh Citation: Immediate sync + Auto Refresh toggle.
3

Appearance

  • Themes: Light, Dark, Blue, Emerald, Sunset.
  • Transparent Overlay: 50%, 75%, 95%, 100%.
  • Box Shape: Round Box or Card Box.
  • Search Options: Custom Match Highlight Colors.
4

Space & Indent

  • Paragraph Spacing: Single, 1.5, Double, Exactly, etc.
  • Special Indents: None, First line, Hanging indents.
  • By Measurement: Custom inches (e.g., 0.25").
5

Font & Style

  • Font & Size: Custom styling for bibliography.
  • Heading Title: "Bibliography", "Works Cited", etc.
  • List Style: Bullets, Numeric (1), [1], etc.
6

Citation & Hyperlink

  • Styles: APA, MLA, Chicago, Harvard, Vancouver.
  • Format: Author (year) or (Author, year).
  • Hyperlinks: Active two-way links & back-references.
  • Cite Button: Quick Search trigger (Alt+C).

📄 7. Save As PDF

Instantly cleans up Word field shading and exports your document layout cleanly to PDF while preserving bookmarks and active hyperlinked citations.

🖱️ 8. Right-Click Context Menu

  • • Edit Format: Switch between Author (year) & (Author, year).
  • • Edit Prefix/Suffix: Add custom text (e.g., "see", "p. 67").
  • • Edit Reference: Open master database to edit source details.
  • • Refresh: Quickly re-sync references on demand.

9. Word Add-in Shortcuts at a Glance

Shortcut Key Action Description
Alt + A Switch between Literature Matrix app and Word, auto-selecting current library.
Alt + C Open Quick Cite search form directly at current cursor location.
Alt + S Jump focus directly to the Literature Matrix Ribbon tab in Word.
Alt + Z Change selected citation format to Author (year).
Alt + X Change selected citation format to (Author, year).
