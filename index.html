Literature Matrix: Word Add-in Guide

Everything you need to write, cite, and format directly within Microsoft Word.

1. Getting Started

  • • Open Literature Matrix: Launches main application to manage master database.
  • • Help: Opens this user guide.

2. Library Setting Group

  • • Current Library: Dropdown to switch active database files.
  • • Open/Switch Library: Manually browse & select database files.
  • • Refresh Citation & Bibliography: Immediate sync + Auto Refresh toggle.

3. Appearance

  • • Themes: Light, Dark, Blue, Emerald, Sunset.
  • • Transparent Overlay: 50%, 75%, 95%, 100%.
  • • Box Shape: Round Box or Card Box.
  • • Text Size: Auto, Small, Medium, Large.
  • • Search Options: Author+Year+Title, All Columns, Custom Match Highlight Colors.

4. Space & Indent

  • • Paragraph Spacing: Single, 1.5, Double, At least, Exactly, Multiple.
  • • Special Indents: None, First line, or Hanging indents.
  • • By Measurement: Custom inches (e.g., 0.25" to 1.5").

5. Font & Style

  • • Font & Size: Custom font face and point sizes for bibliography.
  • • Heading Title: "None", "Bibliography", "References", "Works Cited".
  • • List Style: Bullets, Numeric (1), [1], (1), or custom list formatting.

6. Citation & Hyperlink

  • • Styles: APA, MLA, Chicago, Harvard, Vancouver.
  • • Format: Author (year) or (Author, year).
  • • Hyperlinks: Active two-way links & back-references.
  • • Cite Button: Quick Search trigger (Alt+C).

7. Save As PDF

• Instantly cleans up Word field shading and exports your document layout cleanly to PDF while preserving bookmarks and active hyperlinked citations.

8. Right-Click Context Menu

  • • Edit Format: Switch between Author (year) & (Author, year).
  • • Edit Prefix/Suffix: Add custom text (e.g., "see", "p. 67").
  • • Edit Reference: Open master database to edit source details.
  • • Switch Library & Refresh: Quickly re-sync references on demand.

Main Application

How to Get Started

Launch Literature Matrix, explore your workspace layout, and verify your database connections before beginning your research flow.

Main Application

How to Create a New Library

Press Ctrl + N or click "New Library" in the toolbar to generate a completely fresh, isolated database file for your new project.

Main Application

How to Open a Library

Press Ctrl + O or click "Open Library" in the toolbar to load an existing database (.lima, .litma, or .litsync) into your workspace.

Main Application

How to Add Literature

Press Ctrl + L, click "Add Literature", or right-click the matrix to add a new entry manually. You can also drag and drop .ris, .bib, or .enw files to import references instantly.

Main Application

How to Edit Literature

Press Ctrl + E, click the Edit button in the toolbar, or double-click any row in the matrix to open the literature editor.

Main Application

How to Paste Citation from Google Scholar / Journal

Quickly add references without downloading files. Simply copy the formatted citation text (or BibTeX/RIS string) directly from Google Scholar or any academic journal website, and use the Paste Citation feature to instantly extract the metadata into your database.

Main Application

How to Copy Prompt for AI

Bridge your library with advanced AI. Use the prompt generator to create and copy highly optimized instructions. Paste this prompt into Gemini NotebookLM (or other AIs capable of summarizing documents) alongside your PDFs to extract structured data and insights perfectly formatted for your database.

Main Application

How to Search & Filter Matrix

Use Ctrl + F to focus the search box. You can filter your literature by Category, Reference Type, Assigned Theme, and Attachment Status (PDF attached or missing) using the top toolbar dropdowns.

Main Application

How to Manage Columns & Layout

Drag column headers left or right to reorder them. Click the hamburger menu (☰) to toggle the visibility of specific columns, or adjust the Matrix Font and Font Size dynamically. Note: The first 3 columns are permanently pinned (Freeze Panes).

Main Application

How to Export to Excel & Formats

Press Ctrl + X to export the visible matrix table directly into an Excel (.xlsx) file. You can also right-click rows to export specific references to Word (.docx), RIS, BibTeX, or EndNote formats.

Main Application

How to Import References

Import your existing literature seamlessly. Literature Matrix supports .bib, .ris, and .enw files. You can use the "Import" option from the file menu or simply Drag & Drop the files directly into the application.

Main Application

How to Save As

Duplicate or rename your active database by using the Save As function. This safely creates a new copy of your library file in your chosen directory without altering the original.

Main Application

How to Backup Library (ZIP)

Secure your entire library, including all linked PDF attachments, by creating a comprehensive ZIP backup. This is the recommended method when you need to safely copy or move your library to another PC.

Main Application

Mindmap & Analytics

Right-click the matrix and select "Show Mindmap" (Ctrl + M) or "Show Analytics" (Ctrl + T) to visualize your research groupings, themes, and journal ranks dynamically.

Main Application

Using the Browser Bar

The internal browser bar allows you to search selected references directly across Google Scholar, Scopus, Web of Science, PubMed, and Semantic Scholar without leaving the application.

Word's Add-In

How to Switch App & Word

Press Alt + A or click "Open Main App" in the ribbon to seamlessly toggle your view between the Literature Matrix main application and Microsoft Word.

Word's Add-In

How to Customize Theme

Customize the floating Quick Search panel by selecting a "Search Bar Theme" (Light, Dark, Blue, Emerald, Sunset) and adjusting the "Search Bar Transparency" from 50% to 100%. You can also toggle the corners between "Round Box" and "Card Box".

Word's Add-In

How to Set Space & Indent

Enforce academic line spacing using the "Line Spacing" and "Space After" dropdowns. Apply special paragraph formatting like "Hanging" indents and set the exact measurement using the "Indent Size" tool.

Word's Add-In

How to Set Font & Size

Use the dedicated ribbon controls to instantly adapt all generated citations and reference lists to your exact university or publisher requirements.

Word's Add-In

How to Customize Bibliography Format

Customize your reference list by adjusting the bibliography heading, overall text format, and bullet or numbering styles directly from the ribbon.

Word's Add-In

How to Change Academic Style

Instantly reformat your entire document's citations and bibliography to match standard academic styles such as APA, MLA, Chicago, Harvard, or Vancouver.

Word's Add-In

Footnotes: Insert & Jump

Click "Smart Footnote" to instantly insert a new footnote at your cursor, or click it while inside a footnote to automatically jump back to the main text. Navigate efficiently using the "Previous" and "Next" buttons.

Word's Add-In

How to Cite (Quick Cite)

Press Alt + C to open the Quick Search panel. You can easily switch modes using Alt + Z for integral mode, Alt + X for non-integral mode, or Alt + F for full footnote format.

Word's Add-In

How to Remove a Citation from a Group

To remove specific sources from a multi-citation group, simply Double Click or Right Click the citation block and select "Edit Citation".

Word's Add-In

How to Edit Database

Quickly access and modify your master database directly from Word. You can Right Click a citation and select "Edit Reference", or use the Alt + D keyboard shortcut.

Word's Add-In

Hyperlinks & Back-References

Check "Show Back-References" in the ribbon to append clickable jump-links (e.g. [1] [2]) to the end of your bibliography entries, allowing you to teleport back to the text. Use "Hyperlink URLs" to convert DOIs into active links.

Word's Add-In

Citation Colors & URL/DOI

Change the font color of active in-text citations (Black, Blue, Purple, Teal, etc.) and URL/DOI link from the ribbon to easily review dynamic fields before publishing.

Word's Add-In

How to Export a Clean PDF

Click "Export Clean PDF" to output your current Word document. This action automatically strips out the gray field boxes and converts all your dynamic citations into clickable jump-links within the PDF.
